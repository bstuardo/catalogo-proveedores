Descripción del producto

Máquina manual para la fabricación y ensamblaje de imanes personalizados en formato rectangular de 80 × 53 mm. El sistema permite preparar la impresión, realizar el corte preciso del diseño y ensamblar los diferentes componentes del imán mediante un proceso manual de prensado.

El kit está compuesto por la máquina para fabricar imanes de 80 × 53 mm, cortador/troqueladora para papel y un conjunto de consumibles para la fabricación de imanes.

Especificaciones técnicas de la máquina

Máquina para fabricación de imanes

Tipo: Máquina manual para fabricación y ensamblaje de imanes rectangulares.
Formato de trabajo: 80 × 53 mm.
Forma del producto: Rectangular.
Accionamiento: Manual mediante palanca.
Construcción: Estructura metálica con componentes de soporte.
Función: Ensamblaje y prensado de los componentes necesarios para fabricar imanes personalizados.
Aplicación: Fabricación de imanes personalizados para refrigeradores, recuerdos, regalos, publicidad y productos personalizados.
Requisitos de rendimiento: Prensado uniforme y correcta alineación de los componentes durante el ensamblaje.
Formato compatible: Consumibles rectangulares de 80 × 53 mm.

Sistema de prensado

Tipo: Prensado mecánico manual.
Función: Ejercer presión sobre los componentes para realizar el ensamblaje del imán.
Operación: Accionamiento mediante palanca.
Requisitos de rendimiento: Presión uniforme y correcta posición de las piezas durante el proceso.
Notas: Se recomienda mantener las superficies de trabajo limpias y comprobar la correcta posición de los componentes antes de accionar la palanca.

Especificaciones técnicas del cortador

Cortador / Troqueladora para papel

Tipo: Cortador manual / troqueladora rectangular.
Área de corte: 80 × 53 mm.
Función: Recortar el papel impreso con las dimensiones necesarias para el ensamblaje del imán.
Accionamiento: Manual mediante palanca.
Aplicación: Papel, cartulina y materiales compatibles con el sistema de corte.
Requisitos de rendimiento: Corte preciso y uniforme para obtener piezas compatibles con el formato del imán.
Notas: Se recomienda colocar correctamente el material y realizar el corte de forma individual para obtener mayor precisión.

Proceso básico de fabricación

  1. Preparar el diseño utilizando un formato de 80 × 53 mm.
  2. Imprimir el diseño sobre el material adecuado.
  3. Colocar la impresión en el cortador/troqueladora.
  4. Realizar el corte del diseño utilizando el cortador de 80 × 53 mm.
  5. Preparar la placa frontal, impresión, cubierta protectora y componente magnético.
  6. Colocar los componentes correctamente dentro de la matriz de la máquina.
  7. Accionar la palanca para realizar el prensado y ensamblaje.
  8. Retirar el imán terminado y comprobar que todos los componentes estén correctamente unidos.

Requisitos de calidad

  • Verificar que el diseño tenga las dimensiones adecuadas para el formato de 80 × 53 mm.
  • Comprobar que el corte sea limpio y uniforme.
  • Verificar que la impresión se encuentre correctamente centrada.
  • Comprobar que la cubierta protectora no presente arrugas ni burbujas.
  • Verificar la correcta alineación de los componentes antes del prensado.
  • Comprobar que el imán terminado quede correctamente ensamblado.
  • Verificar la correcta fijación magnética del producto terminado.

Almacenamiento y seguridad

- Utilizar la máquina sobre una superficie plana, estable y resistente.
- Mantener la máquina y el cortador alejados de la humedad.
- Mantener las manos alejadas del área de corte durante la operación del cortador.
- No introducir las manos en la zona de prensado mientras se acciona la palanca.
- Mantener los componentes metálicos limpios y secos.
- Almacenar los consumibles protegidos del polvo, humedad y temperaturas elevadas.
- Mantener los componentes magnéticos alejados de dispositivos electrónicos sensibles.
- Revisar periódicamente tornillos, piezas móviles y elementos de fijación.
