Kit Impresora de Sublimación Adaptada Epson EcoTank L3350 + Tintas + Papel

Comienza tu emprendimiento de personalización con un kit práctico que reúne los elementos esenciales para imprimir tus primeros diseños de sublimación.

Este kit incluye una Epson EcoTank L3350 nueva y adaptada para sublimación, tintas de sublimación CMYK y Papel de Sublimación Todok A4 de 100 g/m².

Es una excelente alternativa para quienes quieren comenzar desde casa, crear productos personalizados o incorporar la sublimación a su negocio.

¿Qué incluye el kit?

1. Impresora Epson EcoTank L3350 adaptada para sublimación

La Epson EcoTank L3350 es una impresora multifuncional compacta que permite imprimir, copiar y escanear.

En este kit se entrega adaptada para trabajar con tintas de sublimación, permitiéndote imprimir tus diseños para posteriormente transferirlos mediante temperatura y presión a productos compatibles con esta técnica.

Su conectividad Wi-Fi facilita el trabajo desde diferentes dispositivos y también permite utilizar Epson Smart Panel desde dispositivos móviles compatibles.

  • Tipo: Impresora multifuncional.
  • Funciones: Imprime, copia y escanea.
  • Tecnología de impresión: Epson Heat-Free Micro Piezo.
  • Sistema de tinta: EcoTank con tanques recargables.
  • Adaptación: Preparada para trabajar con tintas de sublimación.
  • Colores: Cian, Magenta, Amarillo y Negro (CMYK).
  • Velocidad de impresión ISO: hasta 11 ppm en negro y 6 ppm a color.
  • Formato máximo de impresión: hasta tamaño Legal (216 × 356 mm).
  • Capacidad de bandeja: hasta 100 hojas de papel común.
  • Conectividad: Wi-Fi, Wi-Fi Direct y USB.
  • Impresión desde dispositivos móviles: compatible con Epson Smart Panel.

Incluye una resma de 100 hojas de Papel de Sublimación Todok, especialmente diseñado para realizar transferencias mediante sublimación.

Su formato A4 es práctico para comenzar a crear una amplia variedad de diseños.

Ideal para preparar diseños destinados a tazas, poleras, mousepads, cojines, llaveros y otros productos compatibles.

3. Tintas de Sublimación CMYK

El kit incluye los cuatro colores esenciales para realizar impresiones destinadas a sublimación:

  • Cian (C)
  • Magenta (M)
  • Amarillo (Y)
  • Negro (K)

Las tintas están diseñadas para transferirse mediante temperatura y presión sobre superficies compatibles con sublimación.

¿Qué significa que la Epson L3350 sea adaptada para sublimación?

La Epson EcoTank L3350 originalmente es una impresora para tinta convencional. En este kit se entrega nueva y adaptada utilizando tintas específicas para sublimación en sus tanques EcoTank.

Esto permite imprimir diseños que posteriormente pueden transferirse mediante una prensa térmica a productos aptos para sublimación.

Una vez adaptada, recomendamos destinar la impresora exclusivamente a sublimación y no alternar entre tinta convencional y tinta de sublimación, ya que mezclar diferentes tipos de tinta puede afectar el funcionamiento y los resultados de impresión.

¿Qué puedes crear con este kit?

Podrás preparar diseños para personalizar una gran variedad de productos, entre ellos:

  • Tazas aptas para sublimación.
  • Poleras de poliéster.
  • Mousepads.
  • Cojines sublimables.
  • Llaveros.
  • Placas de aluminio sublimables.
  • Cerámica con recubrimiento para sublimación.
  • Bolsas y textiles compatibles.
  • Diferentes artículos preparados especialmente para sublimación.

Importante antes de comenzar

La impresora imprime el diseño, pero no realiza la transferencia al producto final.

Para completar el proceso necesitarás una prensa térmica compatible con el producto que quieras personalizar, como una plancha plana para textiles o una estampadora específica para tazas.

Los productos utilizados también deben ser compatibles con sublimación. En el caso de textiles, se recomienda trabajar con prendas de poliéster o con una composición adecuada para esta técnica. Los productos rígidos deben contar con el recubrimiento correspondiente para sublimación.

¿Por qué los colores se ven diferentes antes de sublimar?

Es normal que algunos colores de la impresión sobre el papel se vean menos intensos antes de realizar la transferencia.

Durante el proceso de sublimación, la aplicación de temperatura y presión permite que la tinta se transfiera al producto, mostrando el resultado final del diseño.
