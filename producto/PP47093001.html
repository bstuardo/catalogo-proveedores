Descripción

El rollo DTF UV es un tipo de película plástica utilizada en el proceso de impresión con tecnología DTF UV.
Además, esta película tiene una excelente capacidad de adherencia y puede ser impresa con una amplia gama de tintas DTF UV para crear imágenes de alta calidad y resolución.
Este se debe usar en conjunto con el Rollo DTF UV Galaxy film B.

Film ideal para la impresión de etiquetas, rótulos, calcomanías y otros productos que requieren una alta calidad y durabilidad.
