Descripción

El Set de Plumas Térmicas Extra Fina es la herramienta definitiva para añadir acabados metalizados y detalles brillantes con una precisión quirúrgica. Gracias a su punta de 0,5 mm, permite realizar trazos extremadamente delgados y diseños complejos que resaltan por su delicadeza y elegancia. Es el accesorio ideal para elevar el valor de invitaciones, tarjetas de felicitación y proyectos de papelería creativa.

Usos comerciales

Accesorio de alta precisión para efectos metalizados extra finos. Totalmente compatible con Cameo 5, Portrait 4 y Curio 2, este set permite transferir foil con un nivel de detalle superior de 0,5 mm, ideal para proyectos de papelería de lujo y personalización avanzada.
