Descripción

El tapete de corte de 30x60 cm de baja sujeción para Plotter ScanNcut de Brother viene con una cuadrícula impresa en centímetros y pulgadas, como guía para realizar los cortes y dibujos en la pantalla. Diseñado para una gran variedad de materiales, es ideal para papeles delicados como papel impreso o vegetal entre 0,1 y 0,3 mm de grosor.

Compatible con los modelos: CM300, CM550 y CM650.

No compatible con los modelos SDX125CL ni SDX225CL.

Usos comerciales

Este tapete tiene un adhesivo que fija el material para cortar y que permite utilizarlo varias veces. Especialmente diseñado para papeles delgados o delicados, como por ejemplo papel para impresora o vitela (grosor comprendido entre 0.1 mm - 0.5 mm). Para utilizar con la máquina Brother ScanNCut/DesignNCut. Este tapete es ideal para utilizar la función de CaptureMat con la máquina DesignNCut.

Garantía

Garantía de 6 meses con MundoTransfer. Excepciones: Daños producidos por el mal uso del producto.
