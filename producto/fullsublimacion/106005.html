Descripción

La carcasa para sublimar Samsung A04 128GB está pensada para quienes personalizan fundas de celular: permite estampar el diseño que pida cada cliente y entregar una carcasa exclusiva. Está hecha a partir del molde original del equipo para lograr un calce perfecto y cubre todos los bordes del dispositivo.

Es un producto para sublimar, con una superficie de aluminio de acabado brillante lista para recibir el diseño que quieras.

Características

  • Hecha a base del molde original del equipo, para obtener un calce perfecto.
  • Cubre todos los bordes del equipo.
  • Bordes de goma antigolpe (TPU) que ofrecen mayor protección al dispositivo móvil.
  • Bordes antideslizantes.
  • Acabado brillante en el aluminio para sublimar.
  • Se puede personalizar con el diseño que se desee.

Especificaciones

  • Producto: carcasa para sublimación
  • Modelo compatible: Samsung A04 128GB
  • Marca de la funda: De Todo y Más
  • Medidas: 16 cm x 8 cm x 1 cm
  • Bordes: goma antigolpe (TPU)
  • Superficie para sublimar: aluminio con acabado brillante
  • Variante: Tamaño Único
  • Condición: nuevo

Ideal para

  • Emprendedores y talleres de sublimación que reciben pedidos de diseños personalizados.
  • Quienes quieren una carcasa exclusiva con su propio diseño, para uso personal o para regalar.
  • Ampliar el catálogo de objetos sublimables con un modelo de celular Samsung.

Antes de comprar, confirma que el celular sea el modelo Samsung A04 128GB, ya que la carcasa está hecha sobre el molde de ese equipo.
