Descripción

El CNC Router 3018 PRO es una máquina enrutadora de 3 ejes con husillo 775 y módulo láser de 0.5W, pensada para grabar y tallar materiales sólidos blandos como la madera. Se controla con software GRBL desde el computador por USB y tiene un área de trabajo de 300x180x40 mm. Es adecuada para aficionados al bricolaje, ingenieros CNC y artistas que quieran un equipo de grabado y tallado en un solo cuerpo.

Características

  • Control numérico por computadora (CNC): la máquina puede trabajar a lo largo de varios ejes, en sentido horizontal o vertical.
  • Tres ejes: permiten un grabado plano y un área de trabajo efectiva de 300 (X) x180 (Y) x40 (Z) mm (11.8inx7.1inx1.57in).
  • Husillo 775 con mandril ER11: impulsa el proceso de mecanizado; la pinza ER11 (3,175 mm) permite conectar la broca al husillo con rapidez.
  • Módulo láser: graba o corta distintos tipos de materiales y espesores.
  • Controlador sin conexión: puede guardar archivos y controlar la máquina para hacer tallados simples sin conectarla a un computador.
  • Conexión USB y software GRBL: controla el movimiento de la máquina desde el computador.
  • Cuerpo de aleación de aluminio de alta dureza, con acabado negro para resistir el óxido.

Especificaciones

  • Cabezal láser: 0.5W
  • Longitud de onda: 450 nm
  • Color: negro
  • Material: aleación de aluminio, plástico y acero
  • Área de trabajo: 300 x 180 x 40 mm (11.8 x 7.1 x 1.6 in)
  • Tamaño del marco: 420 x 355 x 280 mm (16,5 x 14 x 11 pulgadas)
  • Husillo: motor 775 (12-36 V); a 24 V: 7000 r/min, a 36 V: 9000 r/min
  • Mandril de husillo: ER11
  • Motor paso a paso: 1.3A / 0.25 N.m
  • Fuente de alimentación: 24 V / 5.6 A (110-240 V)
  • Software de control: compatible con GRBL
  • Sistema compatible: Windows XP / 7 / 8 / 10
  • Formatos compatibles: jpg, bmp y png

Ideal para

  • Aficionados al bricolaje que quieren grabar o tallar piezas en materiales sólidos blandos, como la madera.
  • Ingenieros CNC que necesitan un equipo compacto de 3 ejes.
  • Artistas y entusiastas que quieren combinar tallado con router y grabado con láser.

Preguntas frecuentes

¿Qué medida de brocas se pueden usar?

La máquina usa una pinza ER11, compatible con brocas de 3,175 mm.

¿Se puede usar con software?

Sí. La máquina es compatible con software GRBL para controlar su movimiento y operación, y funciona con Windows XP, 7, 8 y 10.

¿Sirve para trabajos con profundidades de 0,1 mm a 0,2 mm?

Está diseñada para grabado y tallado con alta precisión, pero no tiene especificaciones técnicas que aseguren una tolerancia de profundidad tan reducida como 0,1 mm o 0,2 mm.

¿Se puede usar sin computador?

Para tallados simples, el controlador sin conexión permite guardar archivos y controlar la máquina directamente. Para usar el software GRBL, se conecta al computador por USB.
