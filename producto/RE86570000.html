Recomendaciones

Recomendaciones de uso:
- Para asegurar cortes exitosos, siempre desactiva el modo de suspensión de tu computador antes de comenzar un proyecto (puede interrumpirse la conexión y reiniciarse el sistema). - No se recomienda para cortar imágenes o detalles más pequeños que 1,9 cm (¾”). - Deberás tener instalado el software Cricut Design Space; no compatible con aplicaciones móviles (cerciórate que esté actualizado). - Asegúrate de que la carcasa con engranaje esté bien colocada. - El engranaje debe conectar con la rueda interna de la máquina. - Después de cada uso, límpiala cuidadosamente para evitar acumulación de polvo o material. - No uses agua, usa aire comprimido o un paño seco y suave. - Para utilizar esta cuchilla, es recomendable complementarla con el tapete de corte StrongGrip de Cricut. - No desarmes la carcasa de transmisión. - Si notas que el engranaje patina o la cuchilla no corta correctamente, revisa que no haya residuos atrapados. - Chequea que no se encuentre desgastada, si no, reemplázala.
